# countdown-timer
海渡のWebページです。<br>
常時現在時刻が年、月、日、分、秒の順で表示されています。<br>
イベントの名前と日付を入力できる欄があり、入力して「カウントダウンを開始」ボタンまたはキーボードの「Enter」を押すと、<br>
その時間までの残り時間をイベント名と合わせて表示させることができます。<br>
時間を過ぎると、その時間からの経過時間が表示されるようになります。<br>
過去の日付も入力でき、その場合もその時間からの経過時間が表示されるようになります。<br>
残り時間や経過時間は、「削除」ボタンで削除できます。リロードしても削除されます。<br>
